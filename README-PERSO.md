# Suivi Nat — version locale

Extension personnelle de suivi du dossier ANEF.

- Aucun service de statistiques communautaires ni lien vers le dépôt d’origine.
- Sauvegarde et restauration Chrome Sync désactivées ; anciennes clés purgées au chargement.
- Connexion à ANEF manuelle ; aucun identifiant transmis par la connexion automatique.
- Historique et exports conservés sur cet appareil. Les exports contiennent des données personnelles.
- Les consultations du dossier contactent les services officiels ANEF.

Installation : `chrome://extensions` → Mode développeur → Charger l’extension non empaquetée.
Après une modification, recharger l’extension et les pages ANEF ouvertes.
